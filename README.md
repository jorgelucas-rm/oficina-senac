  
# Oficina Senac - De Palavras a Emoções: Criando uma IA para Análise de Sentimentos  
  
### Contexto do Projeto  
Este repositório fez parte do projeto **Oficinas com IA** da **Faculdade Senac**, uma série de palestras e oficinas sobre Inteligência Artificial voltadas para aprendizado prático.   
O projeto **"De Palavras a Emoções: Criando uma IA para Análise de Sentimentos"** foi idealizado por **Jorge Martins**🤠 ([jorgelucas-rm](https://github.com/jorgelucas-rm)) e **Luan Kaio** ([Luankaio](https://github.com/Luankaio)) com o objetivo de ensinar alunos a coletar dados, processar textos, treinar modelos de classificação de sentimentos e explorar visualizações como nuvens de palavras e gráficos de distribuição de emoções em avaliações de aplicativos.

### Requisitos e Dependências 🗃  
As bibliotecas utilizadas incluem:  
- Python >= 3.9  
- pandas  
- tqdm  
- seaborn  
- matplotlib  
- pygments  
- scikit-learn  
- wordcloud  
- google_play_scraper  
  
> Todas as dependências podem ser instaladas utilizando o notebook `config.ipynb`.  

### Passos para Executar o Projeto 🛠  
1. Clonar o repositório:
```bash  
git clone <URL_DO_REPOSITORIO>
```

3. Abrir o Jupyter Notebook na pasta `notebooks`.  
  3. Executar a célula de configuração em `config.ipynb` para instalar as dependências.  
  4. Coletar e preparar os dados executando `create-dataset.ipynb`.  
  5. Treinar e avaliar o modelo de análise de sentimentos em `sentiment.ipynb`.  
  6. Explorar visualizações como **nuvens de palavras** e gráficos de distribuição de sentimentos.
